Pokémon Unbound — AI source manifest
=====================================
Recorded 2026-09-03.

WHY THERE IS NO EXTRACTED SOURCE HERE
-------------------------------------
Unbound is not an Essentials game. It is a binary hack of Pokémon FireRed running the
Complete FireRed Upgrade (CFRU) battle engine, written in C. There is no decompilation
and there will not be one — it was never built from a source tree, so there is no
.rxdata to run tools/extract_rxdata.py against.

The AI logic is instead read from the public CFRU repo, which is the engine the ROM
compiles. Not vendored here (20k lines, and it is a live upstream repo) — clone it:

    git clone --depth 1 https://github.com/Skeli789/Complete-Fire-Red-Upgrade

*** VERSION GAP — READ THIS BEFORE CITING ANY LINE NUMBER ***
The ROM is from March 2023. The commit above is from January 2025. Unbound was built
against a pinned private CFRU snapshot that is not published. Nothing in ANALYSIS.md is
verified against the shipped binary. Treat the LOGIC as high-confidence and any SPECIFIC
LINE as indicative. This is the same class of gap as the Ashen Frost meta.txt/bundle
problem.
