# Doubles battle logs

Each run contains 60 individual Pokémon-named battle logs, an `INDEX.txt`, and an
`ALL_BATTLES.txt` containing the complete run. Every turn records the four selected
actions, named targets, actual execution result, damage, status or flinch result,
end-of-turn HP, and Portable AI candidate scores.
